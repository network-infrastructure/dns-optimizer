How DNS-level ad blocking works

When an app tries to load a tracker or ad network domain, a filtering resolver returns 0.0.0.0, ::, or NXDOMAIN instead of the real IP address. The connection never starts.

Limitations to know

DNS blocking cannot remove ads served from the exact same hostname as the main content, such as first-party video ads. Combine it with a browser content blocker for full coverage.
