Why global averages mislead

Public DNS providers route traffic using BGP Anycast. Cloudflare might answer in 6 ms from one fiber provider and 28 ms from another ISP across town. Testing directly from your machine gives the only number that matters.

Warm cache vs cold lookups

Popular domains usually hit the resolver cache in a few milliseconds. Uncached domains depend on how quickly the resolver reaches authoritative nameservers.
