Why real DNS lookups differ from ping

An ICMP ping only measures network round-trip time to an IP address. A real DNS speed test sends RFC 1035 domain queries and measures how fast the resolver returns an A or AAAA record from cache or upstream.

Browser DoH test vs Rust desktop test

Web browsers cannot open raw UDP port 53 sockets or modify system network adapters. The browser test above times CORS-enabled DNS-over-HTTPS endpoints. Install the Rust CLI or desktop app to benchmark UDP/53, TCP/53, DoT, and your current ISP resolver side by side.

dns-optimizer bench --profile speed --protocol udp --runs 3
