Safe switching with automatic backup

Before changing any adapter, DNS Optimizer saves your active nameservers to a local backup file. Running dns-optimizer restore returns your interface to its previous static servers or DHCP default.

Native OS integration

On Windows the tool uses netsh and PowerShell adapter detection. On macOS it updates the active service with networksetup. On Linux it configures NetworkManager via nmcli.
