How to change DNS on Xbox

Press the Xbox button, go to Profile & system, open Settings, select General, and choose Network settings. Open Advanced settings, choose DNS settings, pick Manual, and type the Primary and Secondary IPv4 addresses.

Realistic expectations

Better DNS helps Xbox Live sign-in, Game Pass catalog browsing, and CDN routing. Once a multiplayer match connects, latency depends on your ISP route to the game server rather than DNS.
