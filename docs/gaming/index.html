Honest note about in-game ping

Changing DNS does not lower your in-game ping once your PC or console has connected to a match server. Active game traffic travels directly to the server IP address without consulting DNS again.

What a better DNS actually improves

A fast, reliable resolver speeds up lobby host lookups, store pages, patch CDN selection, and login servers. It also avoids ISP DNS timeouts that cause failed matchmaking requests.
