How to enable Private DNS on Android

Open Settings, tap Network & internet (or Connections on Samsung devices), select Private DNS, choose Private DNS provider hostname, and paste a DoT hostname such as dns.adguard-dns.com or one.one.one.one.

Rust mobile architecture

The dns-core Rust crate compiles to aarch64-linux-android with C-ABI exports and Tauri v2 mobile bindings so Android builds share the exact same benchmark and catalog code as desktop.
